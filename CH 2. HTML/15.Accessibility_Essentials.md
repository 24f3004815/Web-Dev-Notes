# Accessibility Essentials

Web Accessibility (a11y) ensures that websites are usable by everyone, including people with disabilities relying on assistive technologies like screen readers or keyboard navigation.

## Semantic HTML is the Foundation

The best way to build accessible web pages is by using native, semantic HTML elements (`<nav>`, `<main>`, `<button>`, `<form>`). Native elements automatically provide the correct roles and keyboard behaviors to assistive technologies.

> [!CAUTION]
> Do not use `<div>` or `<span>` for interactive elements (like buttons). If you must, you must manually add ARIA roles and keyboard event listeners.

## Image Alternative Text (`alt`)

Every `<img>` tag must have an `alt` attribute describing the image for screen readers or when the image fails to load.

```html
<!-- Descriptive alt text for content -->
<img src="chart.png" alt="Bar chart showing a 20% increase in sales">

<!-- Empty alt for purely decorative images -->
<img src="divider.png" alt="">
```

## Forms and Labels

Inputs must always have a linked `<label>`.

```html
<label for="email">Email Address</label>
<input type="email" id="email" name="email">
```
*Screen reader behavior: Reads "Email Address, edit text" when focusing the input.*

## Keyboard Navigation

Many users navigate the web using only the `Tab` key.
- The `Tab` key moves focus between interactive elements (links, buttons, inputs).
- The `Enter` or `Space` key activates the focused element.

### Managing Focus with `tabindex`
| Value | Behavior |
| :--- | :--- |
| `tabindex="0"` | Makes a non-focusable element focusable in the natural tab order. |
| `tabindex="-1"` | Removes the element from the natural tab order (focusable only via JS). |
| `tabindex="1+"` | Avoid using positive numbers; it disrupts natural page flow. |

## ARIA (Accessible Rich Internet Applications)

ARIA attributes bridge the gap when native HTML cannot convey complex behaviors (like custom dropdowns or modals).

- **`role="button"`**: Overrides element semantics to behave as a button.
- **`aria-hidden="true"`**: Hides content from screen readers (but remains visually visible).
- **`aria-label="Text"`**: Provides a label when no visible text exists (e.g., an icon-only button).
- **`aria-expanded="true/false"`**: Indicates if a collapsible element is open or closed.

```html
<button aria-label="Close menu">X</button>
```
