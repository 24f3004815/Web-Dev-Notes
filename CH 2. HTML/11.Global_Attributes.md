# Global Attributes

Global attributes can be applied to **any** HTML element, though they may not have an effect on all of them.

## Core Global Attributes

| Attribute | Description | Example |
| :--- | :--- | :--- |
| `id` | Defines a unique identifier for the element. Cannot be repeated on the page. | `<div id="header">` |
| `class` | Assigns one or more class names for CSS styling or JS targeting. | `<p class="alert error">` |
| `style` | Applies inline CSS styling directly to the element. | `<span style="color: red;">` |
| `title` | Provides advisory text, usually displayed as a tooltip on hover. | `<abbr title="World Health Organization">WHO</abbr>` |

## Interactivity & Data

| Attribute | Description | Example |
| :--- | :--- | :--- |
| `hidden` | A boolean attribute that hides the element from view. | `<div hidden>` |
| `tabindex` | Controls if and in what order an element receives keyboard focus. | `<div tabindex="0">` |
| `data-*` | Allows developers to store custom data attributes on standard elements. | `<li data-user-id="123">` |
| `contenteditable` | Allows the user to edit the text content of the element. | `<p contenteditable="true">` |
| `draggable` | Specifies whether an element is draggable (Drag and Drop API). | `<img draggable="true">` |
| `dir` | Specifies text direction (ltr, rtl, auto). | `<p dir="rtl">` |

## ARIA Attributes (Accessibility)

ARIA (Accessible Rich Internet Applications) attributes are a subset of global attributes used exclusively for assistive technologies.
- `role="button"`: Redefines an element's semantic meaning.
- `aria-hidden="true"`: Hides content from screen readers but not visually.
- `aria-label="Close"`: Provides an invisible label for screen readers.
