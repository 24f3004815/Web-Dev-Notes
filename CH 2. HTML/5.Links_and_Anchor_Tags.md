# Links and Anchor Tags

Links are the fundamental mechanism that connects web pages together.

## The Anchor Tag (`<a>`)

The `<a>` tag creates a hyperlink to other web pages, files, locations within the same page, or email addresses.

```html
<a href="https://example.com">Visit Example</a>
```

## Essential Attributes

| Attribute | Description |
| :--- | :--- |
| `href` | Specifies the destination URL (Hypertext REFerence). |
| `target` | Specifies where to open the linked document. |
| `title` | Tooltip text displayed on hover. |

### The `target` Attribute

| Value | Behavior |
| :--- | :--- |
| `_self` | Default. Opens in the same window/tab. |
| `_blank` | Opens the link in a new tab or window. |
| `_parent` | Opens in the parent frame. |
| `_top` | Opens in the full body of the window. |

```html
<a href="https://example.com" target="_blank">Opens in new tab</a>
```

## Absolute vs Relative Paths

| Type | Definition | Example |
| :--- | :--- | :--- |
| **Absolute** | Full URL including protocol (`https://`) and domain. Use for external sites. | `href="https://google.com"` |
| **Relative** | Path relative to the current file. Use for internal site links. | `href="/about.html"` or `href="../contact.html"` |

## Linking to Specific Page Sections

You can link to specific sections on the same page using the `id` attribute.

1. Assign an `id` to the target element:
```html
<h2 id="contact-section">Contact Us</h2>
```

2. Link to that `id` using a `#`:
```html
<a href="#contact-section">Jump to Contact</a>
```

## Special Links

### Email Links (`mailto:`)
Opens the user's default email client.
```html
<a href="mailto:someone@example.com?subject=Hello">Send Email</a>
```

### Phone Links (`tel:`)
Prompts the device to make a phone call (mobile-friendly).
```html
<a href="tel:+1234567890">Call Us</a>
```

> [!WARNING]
> Do not use `<a>` for actions that change data or submit forms; use `<button>` instead.
