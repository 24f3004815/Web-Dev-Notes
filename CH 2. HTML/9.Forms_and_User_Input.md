# Forms & User Input

HTML forms collect user input and submit it to a server for processing.

## Basic Structure

```html
<form action="/submit" method="POST">
    <label for="username">Username:</label>
    <input type="text" id="username" name="username" required>
    
    <button type="submit">Submit</button>
</form>
```

### Form Attributes
- `action`: The URL where the form data is sent.
- `method`: The HTTP method used (`GET` or `POST`).
  - **GET**: Appends data to the URL. Use for searches/filters.
  - **POST**: Sends data in the request body. Use for sensitive data and state changes.

## Labels (`<label>`)

Labels improve accessibility and usability. Clicking a label focuses its associated input. Must use the `for` attribute matching the input's `id`.

## Common Input Types (`<input>`)

| Type | Description |
| :--- | :--- |
| `text` | Single-line text field |
| `email` | Email field (validates `@` symbol) |
| `password` | Masks characters |
| `number` | Numeric input (often with increment arrows) |
| `checkbox` | Multi-select toggle |
| `radio` | Single-select toggle (must share the same `name` attribute) |
| `file` | File upload |
| `date` / `time` | Date or time picker |
| `hidden` | Invisible field to pass data to the server |

## Other Form Elements

### Dropdowns (`<select>` & `<option>`)
```html
<select name="country">
    <option value="us">United States</option>
    <option value="uk">United Kingdom</option>
</select>
```

### Multi-line Text (`<textarea>`)
```html
<textarea name="message" rows="4" cols="50"></textarea>
```

### Grouping (`<fieldset>` & `<legend>`)
Groups related form fields visually and semantically.
```html
<fieldset>
    <legend>Personal Info</legend>
    <!-- inputs here -->
</fieldset>
```

## Validation Attributes

HTML5 includes built-in form validation:
- `required`: Field cannot be empty.
- `min` / `max`: Numeric or date constraints.
- `minlength` / `maxlength`: Character count limits.
- `pattern`: Validates against a regular expression.
