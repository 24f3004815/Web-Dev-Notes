# What is HTML?

## Definition

**HTML** stands for **HyperText Markup Language**. It is the standard markup language used to structure content on the web. 

> [!IMPORTANT]
> HTML is NOT a programming language. It is a markup language that describes structure rather than executing logic.

## Breaking Down the Name

| Term | Meaning |
| :--- | :--- |
| **HyperText** | Text that links to other documents, enabling non-linear navigation across the web. |
| **Markup** | Tags applied to text to define its structure and presentation (e.g., heading, paragraph). |
| **Language** | A standardized syntax understood by web browsers. |

## The Web Trio

HTML works in tandem with CSS and JavaScript to create modern web pages.

| Technology | Role |
| :--- | :--- |
| **HTML** | Structure (Content) |
| **CSS** | Presentation (Style) |
| **JavaScript** | Behavior (Logic/Interactivity) |

## A Brief History

| Year | Milestone | Version |
| :--- | :--- | :--- |
| 1991 | Tim Berners-Lee invented HTML at CERN | HTML 1.0 |
| 1995 | First official standard | HTML 2.0 |
| 1997 | Added tables and forms | HTML 3.2 / 4.0 |
| 1999 | Refined standard | HTML 4.01 |
| 2000 | Stricter XML-based rules | XHTML 1.0 |
| 2014 | Modern web APIs introduced | HTML5 |
| Today | Constantly evolving standard | HTML Living Standard |

## Your First HTML File

An HTML file is a plain text file saved with the `.html` extension (e.g., `index.html`).

```html
<h1>Hello World!</h1>
<p>This is my first HTML page.</p>
```
