# Head Section Deep Dive

The `<head>` element contains machine-readable metadata about the document. This data is not displayed to the user on the page itself.

## Essential Meta Tags

`<meta>` tags provide structured metadata to the browser and search engines.

```html
<!-- Character Encoding (Crucial for special chars and emojis) -->
<meta charset="UTF-8">

<!-- Viewport (Crucial for mobile responsiveness) -->
<meta name="viewport" content="width=device-width, initial-scale=1.0">

<!-- SEO Description -->
<meta name="description" content="A brief summary of the page content.">

<!-- Author -->
<meta name="author" content="Your Name">
```

## Page Title (`<title>`)

Defines the document's title. Shown in browser tabs, search engine results, and bookmarks. Must be unique per page.

```html
<title>Home - My Website</title>
```

## Linking External Resources (`<link>`)

Used primarily to link stylesheets, favicons, and pre-loading resources.

```html
<!-- CSS Stylesheet -->
<link rel="stylesheet" href="styles.css">

<!-- Favicon (Browser tab icon) -->
<link rel="icon" type="image/x-icon" href="favicon.ico">

<!-- Preload critical fonts/resources -->
<link rel="preload" href="font.woff2" as="font" type="font/woff2" crossorigin>
```

## Adding Scripts (`<script>`)

Embeds or references JavaScript. Often placed at the bottom of the `<body>`, but can be placed in the `<head>` using `defer` or `async`.

```html
<!-- External Script -->
<script src="app.js" defer></script>

<!-- Inline Script -->
<script>
    console.log("Hello from the head!");
</script>
```
| Attribute | Behavior |
| :--- | :--- |
| (None) | Pauses HTML parsing to download and execute script. |
| `async` | Downloads concurrently, executes immediately upon download completion. |
| `defer` | Downloads concurrently, executes only after HTML parsing is fully complete. |

## Open Graph (Social Media Cards)

Open Graph (OG) tags determine how the page appears when shared on platforms like Twitter, Facebook, and LinkedIn.

```html
<meta property="og:title" content="My Website">
<meta property="og:description" content="Check out my site!">
<meta property="og:image" content="https://example.com/preview.jpg">
<meta property="og:url" content="https://example.com">
```
