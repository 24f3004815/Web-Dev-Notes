# HTML Tags & Elements

## Anatomy of an HTML Element

An HTML element consists of an opening tag, content, and a closing tag.

```html
<p class="intro">Hello, World!</p>
```

- **Opening Tag**: `<p>`
- **Closing Tag**: `</p>` (must include the forward slash `/`)
- **Content**: `Hello, World!`
- **Attribute**: `class="intro"`

> [!IMPORTANT]
> Failure to close tags can cause layout breakage as the browser struggles to determine where an element ends.

## Void Elements (Self-Closing Tags)

Some elements do not enclose content and therefore lack a closing tag. 

| Tag | Purpose |
| :--- | :--- |
| `<br>` | Line break |
| `<hr>` | Horizontal divider |
| `<img>` | Image display |
| `<input>` | Form field |
| `<meta>` | Page metadata |
| `<link>` | External resource link |

*Note: In HTML5, trailing slashes on void elements (e.g., `<br />`) are valid but optional.*

## Attributes

Attributes provide additional configuration for elements. They are placed in the opening tag.

```html
<a href="https://google.com" target="_blank">Click here</a>
```

### Key Rules:
- Defined as name-value pairs (`name="value"`).
- Values should be enclosed in quotes.
- Multiple attributes are space-separated.

### Boolean Attributes
Attributes that do not require a value; their presence indicates `true`.
```html
<input type="text" required disabled>
```

## Nesting Elements

HTML elements can be placed inside other elements, creating a parent-child hierarchy.

```html
<div>
    <h1>Welcome</h1>
    <p>This is <strong>important</strong>.</p>
</div>
```

> [!CAUTION]
> Tags must be closed in the reverse order they were opened. Overlapping tags (e.g., `<a><b></a></b>`) results in invalid HTML.

## HTML Comments

Comments are ignored by the browser and are used for documentation or debugging.

```html
<!-- This is a comment -->
```

## Block vs Inline Elements

| Type | Behavior | Common Examples |
| :--- | :--- | :--- |
| **Block** | Takes full width, forces a new line | `<div>`, `<p>`, `<h1>`-`<h6>`, `<ul>` |
| **Inline** | Only takes necessary width, flows with text | `<span>`, `<a>`, `<strong>`, `<img>` |
