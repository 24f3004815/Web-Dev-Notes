# Images & Media

## Images (`<img>`)

The `<img>` tag embeds an image into the document. It is a self-closing (void) element.

```html
<img src="logo.png" alt="Company Logo" width="200" height="100">
```

### Essential Attributes

| Attribute | Description | Required |
| :--- | :--- | :--- |
| `src` | The path/URL to the image source file. | Yes |
| `alt` | Alternative text for screen readers or if the image fails to load. | Yes |
| `width` | Width of the image in pixels. | Recommended |
| `height` | Height of the image in pixels. | Recommended |

> [!WARNING]
> Always include the `alt` attribute for accessibility and SEO. If an image is purely decorative, use an empty alt attribute (`alt=""`).

## Audio (`<audio>`)

Embeds sound content into a document.

```html
<audio controls>
    <source src="music.mp3" type="audio/mpeg">
    <source src="music.ogg" type="audio/ogg">
    Your browser does not support the audio element.
</audio>
```

### Audio Attributes
- `controls`: Displays play/pause buttons and volume controls.
- `autoplay`: Starts playing automatically (often blocked by browsers).
- `loop`: Restarts automatically when finished.
- `muted`: Mutes the audio output.

## Video (`<video>`)

Embeds video content into a document.

```html
<video width="320" height="240" controls poster="thumbnail.jpg">
    <source src="movie.mp4" type="video/mp4">
    <source src="movie.webm" type="video/webm">
    Your browser does not support the video element.
</video>
```

### Video Attributes
- `controls`: Displays video controls.
- `width` / `height`: Specifies video dimensions.
- `poster`: An image shown while the video is downloading or until the user hits play.
- `autoplay`, `loop`, `muted`: Similar to the `<audio>` tag.

## Iframes (`<iframe>`)

Embeds another HTML page into the current document (commonly used for YouTube videos or Google Maps).

```html
<iframe src="https://www.youtube.com/embed/dQw4w9WgXcQ" width="560" height="315" title="YouTube video"></iframe>
```
