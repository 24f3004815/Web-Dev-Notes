# `<div>` and `<span>`

`<div>` and `<span>` are generic HTML containers. Unlike semantic tags (`<article>`, `<nav>`), they carry **no inherent meaning**. They are strictly used for grouping content for CSS styling or JavaScript targeting.

## The `<div>` Element

- **Type**: Block-level element.
- **Behavior**: Starts on a new line and takes up the full available width.
- **Usage**: Grouping larger blocks of layout, such as sections of a grid, a card component, or a layout wrapper.

```html
<div class="card">
    <h2>Card Title</h2>
    <p>Card content goes here.</p>
</div>
```

## The `<span>` Element

- **Type**: Inline element.
- **Behavior**: Flows with text; only takes up as much width as its content.
- **Usage**: Styling small portions of text or grouping inline elements.

```html
<p>This product is on <span class="highlight-sale">SALE!</span></p>
```

## "Div Soup"

> [!WARNING]
> "Div soup" occurs when developers rely entirely on `<div>` tags instead of semantic HTML. This damages accessibility and SEO.

### Bad Practice (Div Soup)
```html
<div class="header">
    <div class="nav">
        <div class="nav-item">Home</div>
    </div>
</div>
```

### Good Practice (Semantic)
```html
<header>
    <nav>
        <a href="/">Home</a>
    </nav>
</header>
```

**Rule of Thumb**: Only use a `<div>` or `<span>` when no semantic element (like `<header>`, `<main>`, `<section>`, `<em>`, or `<strong>`) is appropriate.
