# HTML Entities & Special Characters

HTML entities are used to display reserved characters or symbols that are not present on a standard keyboard. They prevent the browser from interpreting special characters as HTML code.

## Reserved Characters

Certain characters have syntactical meaning in HTML (like `<` and `>`). To display these characters as text without breaking the code, use their entity references.

| Character | Description | Entity Name | Entity Number |
| :---: | :--- | :--- | :--- |
| `<` | Less than (Opening tag) | `&lt;` | `&#60;` |
| `>` | Greater than (Closing tag) | `&gt;` | `&#62;` |
| `&` | Ampersand | `&amp;` | `&#38;` |
| `"` | Double quote | `&quot;` | `&#34;` |
| `'` | Single quote (Apostrophe) | `&apos;` | `&#39;` |

**Example Usage:**
```html
<p>Use the &lt;div&gt; tag to create a container.</p>
<!-- Output: Use the <div> tag to create a container. -->
```

## Non-Breaking Space

By default, HTML collapses multiple spaces into a single space. To force multiple spaces or prevent text from wrapping at a specific point, use the non-breaking space entity.

| Character | Entity Name |
| :--- | :--- |
| Non-breaking space | `&nbsp;` |

```html
<p>10&nbsp;km</p>
<!-- Keeps "10" and "km" on the same line if text wraps -->
```

## Common Symbols

| Symbol | Description | Entity Name |
| :---: | :--- | :--- |
| `©` | Copyright | `&copy;` |
| `®` | Registered Trademark | `&reg;` |
| `™` | Trademark | `&trade;` |
| `€` | Euro | `&euro;` |
| `£` | Pound | `&pound;` |
| `¥` | Yen | `&yen;` |
| `×` | Multiplication (times) | `&times;` |
| `÷` | Division | `&divide;` |

> [!NOTE]
> Entity names are strictly case-sensitive. `&copy;` works, but `&COPY;` may not.
